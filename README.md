# Mobile Application for Tracking the Execution of Daily Activities

## 📱 Overview

This repository contains the source code for the mobile application developed as part of Viktoriya Pepieva Georgieva's master's thesis on the topic:

**"Mobile Application for Tracking the Execution of Daily Activities"**

The application is designed to support **mental health and well-being** by helping users track, organize, and reflect on their daily habits and creative activities. It serves as a **digital diary**, promoting mindfulness, self-awareness, and gratitude.

---

## 🎯 Purpose

The main goal of the application is to:

- Encourage the formation of **positive habits**
- Promote a **sense of gratitude**
- Provide **psychological support** through **creative and artistic activity tracking**
- Support **self-reflection** and **self-determination**

---

## 💡 Motivation

The idea was inspired by the increasing need for accessible psychological tools, particularly in the **post-COVID-19** era. The application builds upon concepts from psychology, behavioral economics, and software engineering to deliver a meaningful user experience.

---

## 🛠️ Key Features

- Daily activity tracking and visualization
- Gratitude journaling
- Creative task logging
- Gamification elements to boost motivation
- Minimalist, user-friendly interface

---

The application is based on modern research and theories in:
